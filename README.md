# SafeTube

A private, whitelist-only YouTube player for Android.

- Only channels approved by the administrator are ever shown.
- Videos and playlists can be blocked with one tap. Unblocking, and all channel management, need the administrator PIN.
- No ads, no account, no tracking.

## Building

The APK is built by GitHub Actions on every push (see `.github/workflows/android.yml`) and attached to a release.
